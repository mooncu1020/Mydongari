# PLAN V8 — 버추얼온식 이동기

근거: `docs/REFERENCE_MOVEMENT.md`(이하 "사양서"). 지금 이동(V6.1, `MechStateMachine`의 Idle/Run/Dash/DashStop/Air/Landing + 다이내믹 리지드바디)은 지우지 않고 `BernardTuning → 이동기 선택`으로 끈다.

## 1. 단위

- 1u = 기체 키 / 22. 기체 키는 시작할 때 렌더러 경계로 잰다(파티클·트레일·라인 제외, 1~6m 밖이면 2.6m). 1f = 1/60초.
- 수치는 BernardTuning의 새 묶음 `V8 이동기`에 **사양서 원본 단위(u, u/f, f, 각 단위)** 로 둔다. 실행할 때 u → m(키/22), f → 초(1/60)로 바꾼다. 키가 2.6m면 V6 m/s 값과 같다(걷기 3.10u/f = 22.0m/s …).
- V6 BernardTuning의 방향별 속도표(걷기·대시·공중 대시·점프 수평)와 대시 어택 경직은 V8도 그대로 쓴다(값이 사양서와 같음, m/s → u/f는 키 2.6 기준 환산 계수로).

## 2. 틱과 물리

- `Movement/V8/VoTickDriver`(씬에 하나, 런타임 자동 생성): V8이 켜지면 `Time.fixedDeltaTime = 1/60`. `FixedUpdate`(실행 순서 늦게)에서 **카메라 → 1P 전체 → 2P 전체**.
- 기체 안 순서: 입력 → 상태 보조 → 상대 관계 → 자동 선회 → 수평 속력 0 → 상태 메인 → 이동 적분(근접 감속 → 속도 벡터 → 지면 → 벽 → 위치).
- 리지드바디: `isKinematic = true`, 보간 켬, `MovePosition`/`MoveRotation`으로만 옮긴다. 충돌은 판정(겹침·캐스트)에만 쓴다.
- 1P는 2P의 지난 틱 위치, 2P는 1P의 이번 틱 위치를 본다(사양서 비대칭 그대로).

## 3. 외부 속도 통로

- `Movement/V8/MechMotor`(기체마다): 이동기 본체. `ExternalVelocity` + `AddImpulse`/`SetExternalVelocity`.
- `Movement/MotionBridge`(정적 도우미): 전투 코드가 `rb.linearVelocity`·`AddForce`를 직접 쓰던 곳을 `MotionBridge.SetVelocity/AddImpulse/GetVelocity`로 바꾼다. 모터가 켜진 기체면 외부 속도로, 아니면(연습 봇·예전 이동기) 리지드바디에 그대로.
- 외부 모드: 넉백 유지(`IsMoveHeld`), 외부 제어 락(앵커 클로), 예전 상태(런지·넉다운) 중이면 이동 상태 대신 외부 속도로 적분한다(중력·감속(리지드바디 linearDamping)·벽·지면 포함). 사양서 1.4의 "넉백 보간이 진행 중이면 그것만"과 같은 자리.
- 바꿀 곳: `MeleeSystem.ApplyKnockback`, `KnockdownController`, `AnchorClaw`, `ThrusterLunge`, `MechStateMachine.OnHitResolved`, `MechController.ApplyBump`·`SetHorizontalVelocity`, `GameManager` 리스폰, 속도 읽는 곳(카메라 FOV·외형·로그).

## 4. 입력 해석 (`Movement/V8/VoInput`)

- L스틱 → 가상 레버 하나(두 레버가 같은 방향인 것으로). 8방향 코드, 누적값 모델(상승률·감쇠·반대감쇠·임계값, 원거리/근접 표) → 레버 이동 벡터(0.8 ~ 1.2), 상대 거리 보정(8.3m 안 ×0.7, 11.8m까지 선형).
- R스틱 X → 수동 선회 계수(부호 유지 제곱, |s| ≤ 0.05 무시) × 상황별 최대 선회율(2.2절 표, 점프 21°/s 등). 마우스는 이동량 × 감도.
- ○ = 터보(한쪽만): 새 입력·유지를 틱 단위로(InputReader에 누름 횟수 카운터 추가). △ = 레버 벌리기(점프), 공중 L스틱 아래 + ○ = 레버 모으기(급강하, `diveStickY` 튜닝).
- 대시 방향 잠금: 사양서 2.1 규칙 1~3(서기·걷기는 ○ 누른 뒤 15f 안에 스틱이 들어와도 잠김) → "○ 먼저 + 0.25초 안 스틱 = 근접 스텝(근접 구역·서기)".

## 5. 상태 (`Movement/V8/*`, MechState 상속)

서기 / 걷기 / 근접 스텝 / 지상 대시(시작·지속·종료 단계) / 대시 정지 / 점프(이륙·상승·하강, 낙하 포함) / 공중 대시 / 급강하. 착지 경직은 기존 `LandingState` 재사용(12f = 0.2초, 부스트 0% 0.8초 규칙 유지). 런지·넉다운은 기존 상태 그대로(외부 속도로 움직임).
전환표는 사양서 4.9 그대로. 대시 게이지(−200/f, +206/f, 500, 허가 < 24) 구현. 우리 부스트 게이지 소모·탈진 규칙은 유지.

## 6. 선회·자동 선회

- 기본: 수동 선회만. 하드락 몸통 자동 회전은 V8에서 끔.
- 자동 선회 모드: 점프 조준(이륙, 12.66°/f, 정렬되면 끝), 지속 조준(대시 중 공격), 사격 조준(공격 사용 — 펀치·런지 등, 15f 또는 근접 구역 진입까지, 최대 선회율 튜닝, 최대율에 걸린 틱은 수평 속력 × 0.1), 공중 대시 복귀(14.06°/f), 정지 맞춤(카메라).

## 7. 카메라 (`MechCamera` V8 경로)

- 기체 뒤 거리 = 키 × 78/22(3.54), 피치 8.4° 아래, 시선 표적 = 발 + 키/2 + 6u, 기준점이 매 틱 12%씩 기체를 따라감, 세로 FOV 35°. 방위는 기본 모드에서 기체에 강체로 붙고, 점프 조준·공중 대시 중엔 최대 22.5°/f로 쫓는다. 선회 리드 ±8.4°(1.41°/f). 틱 사이 보간해서 그린다.
- V6d 화면 구도 계산식은 지운다(예전 이동기일 때는 V3 고정 백뷰 값으로).

## 8. 지면·벽

- 지면: 발 위 0.59m(5u)에서 아래로 레이(Walkable + 위를 향한 면). 지상 상태는 y를 지면으로 덮어씀, 5u 넘게 아래면 낙하(vy = −0.5u/f), 5u 넘는 오르막은 벽.
- 벽: 캡슐 캐스트(바닥을 5u 들어 올린 캡슐)로 다음 위치를 조회 → 닿으면 법선 성분을 지우고 미끄러짐(정면이면 멈춤). 속력 값은 안 줄임. 천장은 상승 중 머리 위 캐스트 → 급강하.
- 기체끼리: 사양서엔 없지만 키네마틱끼리는 서로 통과하므로 최소 분리(두 캡슐 반경 합) + 대시 몸 충돌 반동(V3)은 유지.

## 9. 전투 연결

- `MechStateMachine`: 이동기 선택에 따라 시작 상태·틱 경로를 고름. `IsDashing`·`IsAirborne`·`IsDashStopping`·`IsIdle`·`IsRunning`·`CanStartLunge` 등은 V8 상태도 포함. 예전 상태로 가는 `ChangeState(IdleState)` 등은 V8이면 대응 상태로 바꿔 넣음(런지·넉다운·사망에서 돌아올 때).
- 대시 질의는 `IDashMove` 인터페이스(`StateMachine.ActiveDash`)로: 방향, 공격 중, 차징, 시작 단계, 태클 요청, 맞딜 판정·종료, 넉백·충돌 종료. 대시 어택·태클 진행은 `DashAttackRunner`(예전 DashState 공격 로직을 V8용으로 옮긴 것). 예전 `DashState`는 그대로 두고 인터페이스만 붙인다.
- 대시 이벤트(로그)는 `MechStateMachine.OnDashStarted/OnDashEnded`로 모은다.
- 연습 봇(MeleeDummy)은 상태 머신·모터가 없어 다이내믹 리지드바디 그대로 — `MotionBridge`가 리지드바디로 보낸다.

## 10. 검증

- 컴파일·batchmode 스모크 테스트. 이동기 스위치를 예전으로 돌려도 컴파일·동작(코드 경로 유지).
- TEST_CHECKLIST에 V8 항목, QUESTIONS에 사양서와 다르게 한 부분.

## 11. 사양서와 다르게 하는 부분 (예정)

- 트윈 레버 → L스틱 하나(두 레버 같은 방향) + R스틱 선회. 제자리 선회 자세·레버 쌍 "방향 없음"은 없음.
- 터보가 하나라 "다른 터보" 조건은 항상 떼어진 것으로. 대시 중 방향 재입력·미확인 파생 상태 없음.
- 급강하 입력은 공중 L스틱 아래 + ○(임시) → 공중 뒤 대시는 못 함.
- 근접 스텝 뒤·대각 속력은 사양서에 없어 정한 값.
- 무기별 사격 조준 선회율 대신 공격 하나의 값.
- 기체끼리 최소 분리·대시 몸 충돌 반동 추가, 벽에 막혀도 대시는 안 끝남(사양서대로, V3.1 벽 종료는 V8에서 끔).
