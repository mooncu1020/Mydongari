# 에디터 확인 체크리스트

Claude Code가 태스크마다 항목을 추가한다. 사용자는 플레이 모드에서 확인하고 체크한다.
형식: `- [ ] (태스크) 무엇을 하면 → 무엇이 보여야 한다`


## Phase A

- [ ] (A0) 컴파일 → Console에 에러 0개
- [ ] (A0) 플레이 → 마우스 왼쪽(또는 패드 RT)으로 공격, 마우스 오른쪽(또는 패드 LT)으로 가드가 이전처럼 동작
- [ ] (A0) 패드 LB → 앵커 클로, RB → 임팩트 슬램 발동 (키보드 Q/E도 그대로)
- [ ] (A0) 키보드 A/D 빠르게 두 번 → 사이드스텝 (이전과 동일)
- [ ] (A0) 패드 오른쪽 스틱으로 시점 회전 → 프레임레이트와 무관하게 일정한 속도 (마우스 감도는 이전과 동일)
- [ ] (A0) 더미에게 펀치·슬램·태클 → 더미만 맞고 내 HP는 줄지 않음
- [ ] (A0) 더미가 가까이 와서 공격 → 내 HP가 줄어듦 (더미가 나를 상대로 인식)
- [ ] (A0) 더미를 카메라 정면에 두면 락온 마커가 더미 위에 표시됨
- [ ] (A0) 플레이 중 Hierarchy에서 Mech·DummyTarget 선택 → `MechIdentity`가 붙어 있고 Opponent가 서로를 가리킴
- [ ] (A1) 더미에게 천천히 다가감 → **기체**와 더미 사이가 6m 이하가 되는 순간 카메라가 더미를 추적하기 시작하고 공격 버튼이 펀치가 됨 (Scene 뷰에서 거리 확인)
- [ ] (A1) 하드 락온 상태에서 뒤로 물러남 → 7m를 넘으면 추적 해제, 공격 버튼이 다시 사격(현재 단계)으로
- [ ] (A1) 하드 락온 중 시점을 크게 돌림(±60° 밖) → 추적 해제
- [ ] (A1) 더미와 나 사이에 엄폐물(Coverfull)을 둠 → 락온 마커가 사라짐
- [ ] (A1) 더미를 화면 밖으로 → 카메라가 더 이상 더미 쪽으로 끌려가지 않음
- [ ] (A2) 전력질주로 부스트를 0까지 씀 → 게이지가 빨간색(탈진), 달리기·질주·사이드스텝·퀵턴 불가
- [ ] (A2) 탈진 후 걷기/정지 → 부스트가 **50%** 에 도달하는 순간 색이 원래대로 돌아오고 달리기 가능 (이전엔 100%)
- [ ] (A2) 걷기/정지 중 가드(우클릭/LT)를 누르고 있음 → 부스트가 전혀 차지 않음. 가드를 놓으면 회복 지연(0.5초) 후 다시 참
- [ ] (A2) 가드를 오래 누르고 있음 → 부스트가 줄지 않음 (가드 비용 없음)
- [ ] (A2) 탈진 상태에서 가드 → 가드가 정상적으로 올라감
- [ ] (A3) 하드 락온 상태에서 펀치 1회 → 히트 게이지가 약 6% 오름 (빗나가도 오름)
- [ ] (A3) 펀치를 계속 연타해 히트 100% → 게이지 빨간색, 공격 버튼을 눌러도 펀치가 안 나감
- [ ] (A3) 과열 후 기다림 → 0%까지 식어야 색이 돌아오고 펀치 가능 (중간에 다시 눌러도 안 나감)
- [ ] (A3) 앵커 클로·임팩트 슬램 사용 → 히트가 오르지 않음
- [ ] (A4) 테스트 준비: 더미 공격을 받으려면 더미 근처에서 가드. 내 HP 감소량을 HUD로 확인 (더미 펀치 25)
- [ ] (A4) 가드를 미리 올려 둔 채(0.15초 이후) 더미 펀치를 받음 → HP 12.5 감소(50%), 히트 +10%
- [ ] (A4) 히트를 100%(과열)로 만든 뒤 가드로 받음 → 가드가 풀리고 HP 25 감소, 0.9초 동안 움직이지 못함(스턴)
- [ ] (A4) 가드를 놓자마자 다시 누름 → 0.4초 동안 가드가 안 올라감 (Inspector Debug 모드에서 MeleeSystem.IsGuarding 확인)
- [ ] (A4) 스턴 중 가드 버튼 → 가드 안 올라감
- [ ] (A4) 전력질주 차징 태클로 가드 중인 더미를 침 → 감쇄 없이 피해 (더미는 가드를 안 하므로 B1 2인 구성에서 재확인)
- [ ] (A5) 더미 펀치 직전에 가드를 새로 누름(0.15초 안) → HP 감소 0, 히트 증가 0
- [ ] (A5) 패리 성공 직후 가드를 놓고 바로 다시 누름 → 대기 없이 즉시 가드가 올라감 (평소엔 0.4초 대기)
- [ ] (A5) 태클 패리는 B1 2인 구성에서 확인: P2가 패리 → P1(태클한 쪽)이 태클 피해만큼 HP가 줄고 뒤로 밀려남, **P1은 스턴 없이 바로 움직일 수 있음**
- [ ] (A5) 태클이 패리되지 않고 맞음 → 이전처럼 태클한 쪽이 0.5초 경직
- [ ] (A6) 더미가 정면 3m 안에 있을 때 펀치 → 더미 HP 25 감소
- [ ] (A6) 더미를 옆(정면에서 45° 이상 벗어난 곳) 또는 뒤에 두고 펀치 → 맞지 않음 (히트는 6% 오름)
- [ ] (A6) 더미가 3m보다 멀 때 펀치 → 맞지 않음
- [ ] (A6) 더미가 다가오면서 내 쪽으로 몸을 돌리고, 정면에서 펀치를 날려 맞힘
- [ ] (A6) 나와 더미가 거의 동시에 펀치 → 둘 다 피해 없이 서로 튕겨남 (맞딜)
- [ ] (A7) 더미가 정면 8m·90° 안일 때 E(패드 RB) → 더미 HP 60 감소, 살짝 떠서 밀려남 (이전과 동일)
- [ ] (A7) 더미가 옆/뒤에 있을 때 슬램 → 안 맞음
- [ ] (A7) 슬램 가드·패리는 B1 2인 구성에서 확인: 가드 중 맞으면 HP 30 감소 + 히트 +10%, 패리하면 피해 0이고 밀려나지도 않음, 과열 가드면 깨짐(60 전부 + 0.9초 스턴)
- [ ] (A8) 게임 시작 → 기체와 카메라가 스폰 포인트 방향을 바라봄
- [ ] (A8) 부스트를 다 쓰고(탈진), 히트를 과열시키고, 앵커 클로·슬램을 쓴 직후 더미를 쓰러뜨림 → 3초 뒤 새 라운드: 두 기체 모두 스폰 위치·방향, HP 100, 부스트 가득, 히트 0, 탈진·과열 색 해제, 앵커 클로·슬램을 즉시 사용 가능
- [ ] (A8) 앵커 클로로 더미를 끌어오는 도중 라운드가 끝나는 상황(더미 HP를 낮춰 두고 파일드라이버) → 다음 라운드에 내 기체와 더미 둘 다 정상적으로 움직임(잠금이 남지 않음)
- [ ] (A8) 하드 락온 중 라운드 종료 → 다음 라운드 시작 시 카메라가 더미를 추적하지 않고 스폰 방향을 봄
- [ ] (A8) 질주 중이거나 가드 중 라운드 종료 → 다음 라운드에 Idle 상태, 가드 내려가 있음, 미끄러지지 않음
- [ ] (A8) 동시 사망(같은 프레임) → 승수 변화 없이 다음 라운드 진행 (재현이 어려우면 B6 로그에서 확인)
- [ ] (A9) 하드 락온 상태에서 카메라를 살짝 돌리거나 더미 주위를 옆걸음 → 기체 몸통이 계속 더미 쪽을 향함 (위아래로는 기울지 않음)
- [ ] (A9) 하드 락온 중 퀵턴(R) → 180° 회전이 몸통 자동 회전에 방해받지 않음
- [ ] (A9) 전력질주 중엔 더미가 6m 안에 있어도 몸통이 더미 쪽으로 돌지 않음
- [ ] (A9) 전력질주 중 히트 냉각이 평소의 약 30% 속도로만 줄어듦
- [ ] (A9) 앵커 클로 → 파일드라이버: 2인 구성에서 상대가 가드·패리를 해도 50 전부 들어감
- [ ] (A9) 키보드 Ctrl/R/Shift/Q/E가 이전처럼 동작 (스킴 그룹 지정 후)

## Phase B

- [ ] (B1) `Mydongari/Setup Versus Scene` 실행 → Hierarchy에 `Mech_P2`, `Canvas_P2`가 생기고 Game 뷰가 좌우로 나뉨
- [ ] (B1) Ctrl+Z → 실행 전 상태로 완전히 돌아감. 다시 실행 후 저장
- [ ] (B1) 패드 2개 연결 후 플레이 → 왼쪽 화면은 패드1, 오른쪽 화면은 패드2로만 움직임 (서로 간섭 없음)
- [ ] (B1) 패드 1개 + 키보드 → 키보드·마우스가 P1(왼쪽), 패드가 P2(오른쪽)
- [ ] (B1) 플레이 중 패드를 뽑았다 다시 꽂음 → 다시 같은 플레이어에 배정됨
- [ ] (B1) 각 화면의 HUD 게이지가 자기 기체 값을 표시 (P1이 질주하면 왼쪽 부스트만 줄어듦)
- [ ] (B1) 각 화면 위쪽에 작은 빨간 상대 체력 바 → 상대를 때리면 줄어듦
- [ ] (B1) 락온 마커가 각 화면에서 상대 기체 위에 정확히 겹침 (화면 분할 좌표 변환 확인)
- [ ] (B1) 소리가 한 번만 들림 (Console에 AudioListener 2개 경고 없음)
- [ ] (B1) `GameManager` → Versus Mode 끄고 플레이 → 전체 화면 1인 + 더미, Phase A 체크 항목이 그대로 동작
- [ ] (B2) 패드 왼쪽 스틱을 살짝(30~80%) 밀기 → 걷기 / 끝까지(80% 이상) 밀기 → 달리기 (Shift 없이)
- [ ] (B2) 스틱 ↑ 튕긴 뒤 곧바로 ↑ 끝까지 밀고 유지(↑↑) → 전력질주(FOV 넓어짐). 스틱을 놓으면 제동(Brake)
- [ ] (B2) 걷기·달리기 중 스틱 ↓ 튕기기 → 즉시 180° 회전(초신지선회)
- [ ] (B2) 스틱 ← 또는 → 튕기기 → 그쪽으로 사이드스텝
- [ ] (B2) 전력질주 중 스틱을 중립으로 튕기고 0.2초 안에 ↗(또는 ↖) → 슬라이딩
- [ ] (B2) 전력질주 중 ↓ 튕기기 / ←→ 튕기기 → 초신지선회 / 사이드스텝
- [ ] (B2) 스틱을 천천히 끝까지 밀었다 천천히 놓음 → 아무 제스처도 안 나감 (그냥 이동)
- [ ] (B2) 키보드 WASD를 톡톡 눌러도 퀵턴·사이드스텝이 저절로 나가지 않음 (A/D 더블탭 사이드스텝, Space 질주, Ctrl 슬라이드, R 퀵턴은 그대로)
- [ ] (B2) 오작동이 잦으면 InputReader → Gesture 수치 조정 후 결과를 QUESTIONS에 기록
- [ ] (B3) 상대가 6m보다 멀 때(또는 락온 없음) 공격 버튼 → 카메라 정면으로 일직선 돌진(약 8m), 부스트 15 감소
- [ ] (B3) 탈진 상태에서 공격 버튼(락온 밖) → 런지가 나가지 않음
- [ ] (B3) 돌진 중 6m 안으로 들어가도 카메라가 상대를 추적하지 않고 방향도 바뀌지 않음
- [ ] (B3) 런지 명중 → 상대 HP 15 감소, 상대 0.5초 스턴. 그 사이 펀치 1회가 들어감(하드 락온 → 펀치)
- [ ] (B3) 가드 중인 상대에게 런지 → 감쇄 없이 15, 상대 히트 증가 없음 (가드 관통)
- [ ] (B3) 상대가 패리(가드 막 올림) → 런지한 쪽이 HP 15 감소 + 뒤로 튕김, 스턴 없음
- [ ] (B3) 상대가 사이드스텝으로 피함(빗나감) → 돌진 끝난 뒤 0.6초 동안 하드 락온이 안 걸림 → 그 뒤 다시 걸림
- [ ] (B3) 벽에 대고 런지 → 1초 안에 돌진이 끝남(멈추지 않고 갇히지 않음)
- [ ] (B3) 런지는 히트를 올리지 않음
- [ ] (B3) 상대가 슬라이딩 → 내 락온 마커가 사라지고 하드 락온 해제, 슬라이딩(0.8초) 끝난 뒤 다시 잡힘
- [ ] (B3) WeaponSystem → Ranged Mode를 Projectile로 바꾸면 이전처럼 사격(투사체 프리팹 연결 필요)
