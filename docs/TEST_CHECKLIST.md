# 에디터 확인 체크리스트

Claude Code가 태스크마다 항목을 추가한다. 사용자는 플레이 모드에서 확인하고 체크한다.
형식: `- [ ] (태스크) 무엇을 하면 → 무엇이 보여야 한다`


## Phase A

- [ ] (A0) 컴파일 → Console에 에러 0개
- [ ] (A0) 플레이 → 마우스 왼쪽(또는 패드 RT)으로 공격, 마우스 오른쪽(또는 패드 LT)으로 가드가 이전처럼 동작
- [ ] (A0) 패드 LB → 앵커 클로, RB → 임팩트 슬램 발동 (키보드 Q/E도 그대로)
- [ ] (A0) 키보드 A/D 빠르게 두 번 → 사이드스텝 (이전과 동일)
- [ ] (A0) 패드 오른쪽 스틱으로 시점 회전 → 프레임레이트와 무관하게 일정한 속도 (마우스 감도는 이전과 동일)
- [ ] (A0) 더미에게 펀치·슬램·태클 → 더미만 맞고 내 HP는 줄지 않음
- [ ] (A0) 더미가 가까이 와서 공격 → 내 HP가 줄어듦 (더미가 나를 상대로 인식)
- [ ] (A0) 더미를 카메라 정면에 두면 락온 마커가 더미 위에 표시됨
- [ ] (A0) 플레이 중 Hierarchy에서 Mech·DummyTarget 선택 → `MechIdentity`가 붙어 있고 Opponent가 서로를 가리킴
- [ ] (A1) 더미에게 천천히 다가감 → **기체**와 더미 사이가 6m 이하가 되는 순간 카메라가 더미를 추적하기 시작하고 공격 버튼이 펀치가 됨 (Scene 뷰에서 거리 확인)
- [ ] (A1) 하드 락온 상태에서 뒤로 물러남 → 7m를 넘으면 추적 해제, 공격 버튼이 다시 사격(현재 단계)으로
- [ ] (A1) 하드 락온 중 시점을 크게 돌림(±60° 밖) → 추적 해제
- [ ] (A1) 더미와 나 사이에 엄폐물(Coverfull)을 둠 → 락온 마커가 사라짐
- [ ] (A1) 더미를 화면 밖으로 → 카메라가 더 이상 더미 쪽으로 끌려가지 않음
