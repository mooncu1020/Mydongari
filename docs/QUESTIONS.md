# 질문과 임시 결정

스펙이 애매할 때 Claude Code가 고른 기본값과 질문을 적는다. 사용자가 답을 달면 다음 작업에서 반영한다.

| 태스크 | 질문 | 고른 기본값 | 사용자 답 |
| --- | --- | --- | --- |
| B4 | 차징된 전력질주로 상대에 닿기만 해도 태클이 자동 발동하는 기존 동작을 유지할까? | 유지 (버튼 태클과 둘 다) | |
| A0 | 새 패드 바인딩(RT/LT/LB/RB)은 `Gamepad` 컨트롤 스킴 그룹에 넣었다. 기존 Slide/Quickturn/Run/Skill 키보드 바인딩은 스킴 그룹이 비어 있는데, B1에서 장치 페어링 시 이 바인딩들이 P2 패드 플레이어에게도 열려 있을 수 있다. 그룹을 `Keyboard&Mouse`로 지정해도 될까? (기존 바인딩 수정이라 보류) | 기존 바인딩 그대로 둠 | |
| A0 | 공격 패드 바인딩에 기존 `buttonWest`(X/□)도 남아 있다. RT와 둘 다 공격으로 둘까? | 둘 다 유지 (기존 바인딩 삭제 금지 규칙) | |
| A1 | 소프트 락온 "정면 30° 원뿔"이 반각 30°(전체 60°)인지 전체 30°(반각 15°)인지? 현재 코드는 반각 30°. | 현재 동작(반각 30°) 유지 | |
| A2 | 스펙의 "탈진 = 이동 속도 저하"를 현재 코드는 "달리기·질주 봉쇄(걷기 속도로 제한)"로 구현하고 있다. 걷기 속도 자체도 더 느리게 할까? | 현재 동작 유지 (추가 감속 없음) | |
| A3 | `HeatGauge.IsSkillActive`(true면 냉각 정지)는 어디서도 true로 세팅되지 않아 현재 아무 효과가 없다. "스킬은 히트를 올리지 않는다" 규칙과 직접 충돌은 없지만, 스킬 사용 중 냉각을 멈추는 의도였다면 스킬 쪽에서 켜 줘야 한다. 그대로 둘까, 지울까? | 그대로 둠 (동작 영향 없음, 라운드 리셋 때 false로 초기화) | |
| A3 | 전력질주 중 냉각 감소(`sprintCoolingPenalty`)가 0.2(=냉각 80% 유지)다. 스펙은 "크게 떨어진다/급감". 값을 올릴까? | 코드 값 유지, 인스펙터에서 조정 | |
