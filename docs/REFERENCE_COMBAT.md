# TEMJIN 전투 뼈대 사양서 (근접전 · 피격 반응 · 기체 충돌 · 처리 순서)

대상: 템진, 일반 스테이지(특수 물리 없음, 스테이지 속도 계수 1.0). 이동 사양서(`MOVEMENT_SPEC_clean.md`)의 후속 문서다.
이 문서는 동작만 서술한다. 무기(탄)·V아머·게이지·체력 계산식은 범위 밖이다. 피해량 숫자는 반응 판정에 필요한 범위에서만 언급한다.

## 0. 표기와 환산

| 항목 | 원본 | 환산 | 비고 |
|---|---|---|---|
| 거리 | 1 u | 0.0877 m | 기체 키 22 u = 1.93 m 기준 (이동 사양서의 2.6 m 기준을 이번에 교체) |
| 시간 | 1 f | 1/60 s | 논리 60 f/s 고정 |
| 속도 | 1 u/f | 5.26 m/s | |
| 가속 | 1 u/f² | 316 m/s² | |
| 각도 | 65536 = 360° | 1 단위 = 0.00549° | 256 단위/f = 1.41°/f = 84°/s |

확신도:
- **높음**: 처리 경로를 끝까지 확인했다.
- **중간**: 흐름은 확인했으나 일부 값·조건 해석이 남아 있다.
- **낮음**: 정황 추정이거나 자료가 불완전하다.

용어:

| 용어 | 뜻 |
|---|---|
| 상대 거리 | 두 기체 중심 사이 수평 거리 |
| 높이차 | 내 높이 − 상대 높이 (내가 위면 +) |
| 상대 방위 오차 | 상대가 있는 방위 − 내 기체 정면 방위 |
| 공격 방향 | 공격자 → 피격자 방위(근접), 또는 탄의 진행 방위(사격). 피격측의 밀려나는 방향이 된다 |
| 무기 버튼 A / B / C | **[2차 확정]** A = 오른쪽 레버 트리거 단독, B = 왼쪽 레버 트리거 단독, C = 두 트리거 동시(6.4절). 좌·우는 이동 사양서의 "레버 A = 왼쪽" 가정(중간)을 따른다 |
| 충격치 누적값 | 피격마다 공격의 충격치가 더해지고 매 프레임 줄어드는 값. 반응 단계를 정한다(2.1절) |
| 행동 가산치 | 공격 동작을 할 때 붙는 추가 충격치. 반응 문턱을 사실상 낮춘다 |
| 사격 무적 / 근접 무적 | 각각 사격 계열·근접 계열 피격을 통째로 무시하는 남은 프레임 |
| 히트스톱 | 맞은 순간 모션과 수평 이동이 멈추는 구간 |

## 1. 근접전 시스템

### 1.1 근접 공격으로 바뀌는 조건 — 높음 (구역 수치), 중간 (버튼 대응)

무기 버튼을 눌렀을 때 그 버튼에 대응하는 **근접 구역** 안에 상대가 있으면, 사격 대신 근접 공격이 나간다. 구역은 버튼마다 따로 있고 매 프레임 계산된다.

**구역 판정은 거리만 보지 않는다. 높이차 창, 거리, 정면 원뿔(각도)을 모두 본다.**

| 구역 | 대응 버튼 | 바깥 거리 | 안쪽 원 반지름 | 원뿔 반각 | 원뿔 꼭짓점 위치 |
|---|---|---|---|---|---|
| A | 버튼 A | 70 u (6.14 m) | 12.5 u (1.10 m) | 42.2° | 내 뒤 16.8 u (1.47 m) |
| B | 버튼 B | 60 u (5.26 m) | 12.5 u (1.10 m) | 50.6° | 내 뒤 19.3 u (1.69 m) |
| C | 버튼 C(동시) | 100 u (8.77 m) | 15 u (1.32 m) | 32.3° | 내 뒤 16.0 u (1.41 m) |

판정 순서 (구역마다 같다):

1. **높이차 창**: 높이차가 −24 u(2.11 m)보다 낮거나 +13 u(1.14 m)보다 높으면 모든 구역이 꺼진다. 즉 상대가 최대 2.11 m 위, 1.14 m 아래까지만 허용한다.
   - 예외 1: 내가 점프 이륙 중(이륙 2프레임)이거나 점프 근접 공격 중이면 높이차 창을 보지 않는다.
   - 예외 2: 상대가 점프 근접 공격 중이면 아래 한계만 −30 u(2.63 m)로 넓혀 본다.
   - 예외 3: 상대가 특수 보스형 기체면 근접 구역이 아예 켜지지 않는다(낮음).
2. **안쪽 원**: 상대 거리 ≤ 안쪽 원 반지름이면 각도와 무관하게 구역이 켜진다("밀착" 표시도 함께 켜짐).
3. **원뿔**: 그 밖이면 상대 거리 < 바깥 거리이고, 다음 원뿔 안에 상대가 있어야 한다.
   - 원뿔 꼭짓점 = 내 위치에서 정면 반대쪽으로 (2 × 안쪽 원 반지름 × sin 반각)만큼 뒤로 물린 점.
   - 꼭짓점에서 상대를 본 방위와 내 정면의 차가 반각보다 작아야 한다.
   - 꼭짓점을 뒤로 물렸기 때문에, 가까운 거리에서는 실질 허용 각이 반각보다 넓다. 바깥 거리 쪽으로 갈수록 반각에 수렴한다.
4. 거리 비교에는 "들어올 때" 값과 "유지할 때" 값이 따로 있으나 템진은 두 값이 같다(70/60/100). 히스테리시스는 없다.

**버튼 → 근접 전환**

| 입력 | 확정 시점 | 근접 판정 창 |
|---|---|---|
| 버튼 A 또는 B 단독 | 누른 뒤 약 2 f 동안 다른 버튼을 기다렸다가 단독으로 확정 | 확정 후 1~4 f째에 해당 구역이 켜져 있으면 근접 |
| 버튼 C (두 버튼 동시) | 두 번째 버튼이 첫 버튼 뒤 약 3 f 안에 눌리면 동시로 확정 | 확정 후 2 f째 한 프레임 |

- 구역이 켜져 있으면 그 버튼의 사격은 억제되고 근접만 나간다.
- 터보 A를 막 누른 직후(약 12 f 이내)에는 근접 전환 자체가 꺼진다(중간). 대시 계열 입력과 겹칠 때 사격·대시 공격을 우선하려는 처리로 보인다.
- 근접 변형 선택:

| 조건 | 버튼 A | 버튼 B | 버튼 C |
|---|---|---|---|
| 기본 (서기·걷기) | 근접 A1 | 근접 B1 | 근접 C1 |
| 터보 B를 막 누른 상태 | 근접 A2 | 근접 B2 | 근접 C2 |
| 레버 모으기(앉은 자세) 상태 | 앉아 근접 A | 앉아 근접 B | 앉아 근접 C |
| 점프 이륙 2 f 안 | 점프 근접(공중) | 점프 근접 | 점프 근접 |

  A2·B2·C2는 모두 **강타**다(1.6절, 가드를 깬다). 서기 상태에서 버튼 C2를 쓰면 별도 특수 상태로 들어가는 경로가 있으나 자세히 보지 않았다(낮음).

### 1.2 근접 공격의 진행 단계 — 높음

근접 공격은 상태를 바꾸지 않는다. 서기 상태 안의 무기 하위 상태로 돈다. 모션은 세 단계다.

| 단계 | 하는 일 | 입력 잠금 |
|---|---|---|
| ① 파고들기 | 속력이 0에서 기준 속력까지 선형으로 오름 (속력 = 기준 × 진행 프레임 / 단계 길이) | 잠금 없음 → 점프·대시로 취소 가능 |
| ② 공격 | 기준 속력 유지. 판정 창 안에서만 공격 판정이 켜짐 | 판정 창 시작 전에는 잠금 없음, 판정 창 시작부터 이 단계 끝까지 잠금 |
| ③ 후딜 | 속력 0 | 서서 하는 근접은 잠금 없음(곧바로 점프·대시 가능). 앉아 근접·A2/B2/C2는 표의 잠금 프레임까지 잠금 |

**템진 근접 수치표** (판정 창은 ② 단계 안의 프레임 번호, 0부터 셈)

| 변형 | 기준 속력 | ① | ② | ③ | 판정 창 | 후딜 잠금 | 피해 | 충격치 | 피격 판정 종류 |
|---|---|---|---|---|---|---|---|---|---|
| A1 1타 | 7.251 u/f (38.2 m/s) | 16 f | 10 f | 22 f | 3~9 | 0 | 290 | 500 | 일반 근접 |
| A1 2타 | 위 × 0.75 | (미확인) | | | 3~9 | 0 | 130 | 1100 | 일반 근접 |
| ~~A1 3타~~ | **[2차 정정]** 템진은 도달 불가(6.2절) | | | | — | | | | |
| B1 1·2타 | 5.551 u/f (29.2 m/s) | 22 f | 12 f | 32 f | 3~8 | 0 | 340 / 180 | 750 / 1100 | 일반 근접 |
| ~~B1 3타~~ | **[2차 정정]** 템진은 도달 불가 | | | | — | | | | |
| C1 | 6.7 u/f (35.3 m/s) | 22 f | 14 f | 34 f | 6~8 | 0 | 380 | 1100 | 근접 계열 2 |
| A2 | 4.0 u/f (21.1 m/s) | 32 f | 10 f | 34 f | 2~6 | 24 f | 435 | 1100 | **강타** |
| B2 | 4.8 u/f (25.3 m/s) | 20 f | 10 f | 38 f | 5~8 | 24 f | 410 | 1100 | **강타** |
| C2 | 5.601 u/f (29.5 m/s) | 30 f | 18 f | 36 f | 4~9 | 32 f | 460 | 11000 | **강타** |
| 앉아 A | 5.901 u/f (31.1 m/s) | 20 f | 12 f | 38 f | 6~11 | 38 f | 220 | 20000 | 일반 근접(앉아 표시) |
| 앉아 B | 4.501 u/f (23.7 m/s) | 24 f | 14 f | 32 f | 2~13 | 32 f | 260 | 20000 | 일반 근접(앉아 표시) |
| 앉아 C | 5.901 u/f (31.1 m/s) | 28 f | 16 f | 46 f | 5~9 | 46 f | 340 | 20000 | 일반 근접(앉아 표시) |

- 연속기(콤보): A1·B1은 ② 단계 동안 같은 버튼을 다시 누르면 예약되고, ② 단계가 끝날 때 다음 타로 넘어가 ①부터 다시 돈다. **[2차 정정] 템진은 최대 2타다.** 3타째로 넘어가는 조건이 특정 두 기체 전용이다. 템진의 3타째 공격은 판정 형상도 0개라 데이터상으로도 쓰이지 않는다(6.2절). 2타의 기준 속력은 1타의 0.75배다. 2타째에서 다른 버튼을 예약하면 다른 근접으로 갈아탈 수 있다(기체 종류에 따라 조건이 다름, 템진은 1타째에서만, 중간).
- 2·3타의 모션 길이는 같은 모션을 다른 구간으로 재생하는 방식이라 프레임 수를 확정하지 못했다(낮음).
- 판정 창의 끝 번호는 "그 번호 직전까지"다. 표의 "3~9"는 ② 단계 3 f째부터 9 f째까지 켜진다는 뜻이다.
- 공격이 한 번 맞으면 그 프레임에 판정이 꺼진다. 다음 프레임에 판정 창이 아직 남아 있으면 다시 켜진다. 같은 휘두르기의 재타격은 피격측 근접 무적(2.4절)으로만 막힌다. 그래서 반응이 없는 약한 피격에서는 다단 히트가 날 수 있다(낮음).
- **빗나갔을 때**: 별도 처리가 없다. 모션은 ②→③을 그대로 끝까지 재생한다. ③이 끝나면 서기로 돌아간다. 경직 프레임은 붙지 않는다. 다만 앉아 근접과 강타는 ③ 전체가 잠금이므로 빗나가면 그만큼 무방비다.

### 1.3 파고들기: 이동 방향·속력 보정·추적 — 중간 (흐름 높음)

**진행 방향**: 기체 정면 방향. 레버 이동 벡터는 쓰지 않는다. 추적은 기체를 돌려서 진로를 바꾸는 방식이다.

**추적이 켜지는 조건**: 근접 시작 프레임에 상대 거리 < 100 u(8.77 m)일 때만 추적 카운터가 시작된다. 100 u는 세 구역 바깥 거리 중 최댓값이다. 추적 카운터는 매 프레임 1씩 오른다.

**추적 회전**(기체 정면을 표적 쪽으로 돌림):
- 표적은 상대 위치를 그대로 쓰지 않는다. 이동 사양서의 "지연 표적 위치"를 쓴다. 같은 행동 15 f 이상이면 반씩 따라가는 값이다.
- 회전은 추적 카운터 15 f째까지만 한다. 상대가 어느 구역의 안쪽 원에 들어오면 그 즉시 끝난다.
- 그 프레임의 필요 회전량이 최대 회전율을 넘으면 최대 회전율만큼만 돌고, **그 프레임 파고들기 속력에 0.1을 곱한다**(옆으로 빠지는 상대를 따라가지 못하면 거의 멈춤).

| 변형 | 최대 회전율 |
|---|---|
| A1 | 848 단위/f = 4.66°/f (280°/s) |
| B1 | 592 = 3.25°/f (195°/s) |
| C1 | 512 = 2.81°/f (169°/s) |
| A2 | 768 = 4.22°/f (253°/s) |
| B2 | 512 = 2.81°/f (169°/s) |
| C2 | 256 = 1.41°/f (84°/s) |
| 앉아 A / B / C | 80 = 0.44°/f / 336 = 1.85°/f / 0 (회전 없음) |
| 점프 근접 (A·B·C 공통) | 2560 = 14.06°/f (844°/s) |
| 가드 반격 | 고정 소값(정확한 값 미확인, 낮음) |

> 정정: 이동 사양서 2.3절 "사격 조준" 모드의 12개 최대 선회율은 무기별 사격용이 아니었다. 위 표의 근접 추적 회전율이다. 서서 쏘는 일반 사격은 이 모드에서 회전량이 0이다.

**속력 보정**(이동 적분에서 매 프레임, 이 순서):
1. 상대 거리 < 200 u(17.5 m)면 × 0.78 (이동 사양서의 근접 감속, 근접 중에는 사실상 항상 걸림).
2. 히트스톱 중이면 수평 이동 0.
3. 추적 카운터가 32 f를 넘으면 속력 0, 추적 종료. 이후 이 휘두르기는 더 전진하지 않는다.
4. 상대 거리 > 20 u(1.75 m)이고 상대가 정면 ±22.5° 밖이면 × 0.5.
5. **정지 거리**: 상대 거리가 다음 값 이하가 되면 속력 0, 추적 종료.
   - A 계열·B 계열: 12.5 u (1.10 m)
   - C 계열: 15 u (1.32 m)
   - 대시 근접: 15 u (세 값 중 최대)
6. **넘어가기 방지**: 속력이 현재 상대 거리보다 크면 속력 = 상대 거리.
7. 추적 카운터가 시작되지 않았거나 이미 끝났으면(0이면) 근접 중 수평 이동이 없다(중간).

실효 최고 속력 예: A1 7.251 × 0.78 = 5.66 u/f(29.8 m/s). 파고들기 구간 평균 2.83 u/f × 16 f ≈ 45 u. 공격 구간 5.66 u/f × 10 f ≈ 57 u. 실제로는 정지 거리 12.5 u에서 멈춘다.

**근접 중 이동·선회 제한** — 높음
- 걷기로 넘어가지 않는다. 레버 이동 벡터는 무시한다.
- 수동 선회(레버 차동)를 0으로 지운다. 기체 방향은 추적 회전으로만 바뀐다.
- 점프·대시는 1.2절 표의 "잠금 없음" 구간에서만 받는다. 이것이 근접 취소다.
- 파고들기 ① 단계에서 레버를 모으면 가드로 바로 넘어갈 수 있다(1.5절 조건 충족 시, 중간).

### 1.4 공격 판정(맞았는지) — 중간

- 구역 판정(1.1절)은 "근접을 낼지"만 정한다. **실제 명중은 3D 형상 겹침**으로 따로 판정한다.
- 공격측: 근접 종류별로 정해진 공격 형상 목록이 골격 관절에 붙는다. 형상은 구, 관절 방향으로 늘린 타원체, 선분 등 여러 종류다.
- 피격측: 골격 관절에 붙은 피격 구 목록.
- 구–구 판정: 중심 거리 < (공격 반지름 × 공격자 크기 배율) + (피격 반지름 × 피격자 크기 배율)이면 명중.
- 판정 창 프레임에만 검사한다. 명중하면 첫 번째로 겹친 피격 구 번호를 함께 기록한다.
- **[2차 확정]** 형상 표는 모델 파일이 아니라 게임 모듈 안의 기체별 고정 표에 있다. 수치는 6장에 정리했다.

### 1.5 가드 — 중간 (흐름), 낮음 (피해 감소율)

**입력**: **레버 모으기**. 별도 버튼은 없다.

**들어가는 조건** (서기·걷기, 그리고 근접 파고들기 중):
- 레버 모으기를 시작한 지 4~24 f 사이다. 막 모은 직후 4 f는 앉아 공격·점프와 구분하려고 비워 둔다.
- 상대가 어느 근접 구역(원뿔 또는 안쪽 원) 안에 있다.
- 상대 방위 오차가 ±112.5° 안이다.
- 무기 버튼 입력이 대기 중이지 않다.

**가드 모션**: 시작 4 f → 유지 32 f(반복) → 해제 8 f.

**유지 조건**: 레버를 계속 모으고 있고, 위 구역·방위 조건이 계속 참이다. 하나라도 깨지면 해제 단계로 가고, 해제가 끝나면 서기로 돌아간다.

**가드 중 이동**: 수평 이동 없음, 수동 선회 없음(중간).

**막는 범위**:

| 받은 공격 | 결과 |
|---|---|
| 일반 근접(서서 하는 A1·B1·C1·점프 근접 등) | **막음**: 가드 경직(아래)과 근접 무적 16 f. 반응 단계는 무시. **[2차 확정]** 피해는 원래 값의 **6%**, 충격치 누적은 **10%**(강타 계열은 20%)만 들어감(6.3절) |
| 앉아 근접 | 반응 쪽은 막는 경로를 타지만 충격치가 20000이라 2.1절 "날아감" 문턱을 넘어 **가드가 깨진다**. 피해 감소도 적용되지 않음 |
| 강타(A2·B2·C2 계열) | **가드 불능**: 무조건 날아감. **[2차 확정]** 단 피해 계산은 반응보다 먼저 하므로 가드 중이었다면 피해는 6%만 들어간다 |
| 충격치 누적값 ≥ 1200(날아감 문턱) | 가드가 깨지고 날아감 |
| 사격 | 막지 못함. 일반 피격 반응(2장) |

**가드 경직(가드 히트)**: 모션 4 f + 12 f = 16 f(0.27 s). 공격 방향으로 1.4 u/f(7.4 m/s) 밀린다. 끝나면 가드 유지로 돌아간다.

**가드 반격**: 가드 유지 단계에서 근접 구역 안 상대에게 버튼 A 또는 B 근접 입력을 넣으면 반격 근접이 나간다.

| 반격 | 기준 속력 | ① / ② / ③ | 판정 창 | 피해 / 충격치 |
|---|---|---|---|---|
| 버튼 A 반격 | 1.8 u/f | 12 / 10 / 22 f | 2~9 | 250 / 500 |
| 버튼 B 반격 | 1.8 u/f | 18 / 12 / 32 f | 3~8 | 300 / 750 |

### 1.6 근접끼리 부딪힐 때(상쇄) — 중간

- **전용 상쇄 처리는 없다.** 공격 형상끼리의 충돌도 검사하지 않는다.
- 두 근접은 각자 독립적으로 상대 몸통을 판정한다. 승패는 처리 순서(4장)로 갈린다.
  - 1P의 근접 판정은 2P 갱신 직전에 돈다. 2P는 같은 프레임 갱신 첫머리에 그 피격을 처리한다.
  - 반응(경직·다운·날아감)으로 넘어가면 2P의 근접 판정 플래그가 꺼진다. 그래서 2P는 그 프레임에 반격 판정을 하지 못한다.
  - 2P가 먼저(앞 프레임에) 맞혔다면 1P는 다음 프레임 갱신 첫머리에 반응으로 넘어가서 판정이 꺼진다.
  - 결과적으로 **같은 프레임 맞교환에서는 1P가 이긴다.** 상호 타격은 피격측에 반응이 없는 약한 타격(충격치 < 200)일 때만 성립한다.
  - 재현 시 이 비대칭을 지키거나, 두 기체의 판정을 모은 뒤 동시에 반영하도록 바꾸고 그 사실을 명시해야 한다.
- 근접 중인 상대에게 근접이 맞을 때의 특례는 가드(1.5절)뿐이다. 그 밖에 특정 다른 기체 하나에만 있는 반격 분기가 있으나 템진과 무관하다.

### 1.7 점프 근접·대시 근접 — 중간(점프), 낮음(대시)

- **점프 근접**: 점프 이륙 2 f 안에 근접 조건이 성립하면 나간다. 점프 입력 후 8 f 이내 조건도 붙는다. 전용 공중 행동 상태로 들어가고 vy = 3.80 u/f(20.0 m/s)로 뛴다. 진로는 기체 정면이다. 추적 회전율은 14.06°/f로 크다. 높이차 창 예외가 적용된다(1.1절).
- **대시 근접**: 지상 대시 지속 단계에서 근접 무기를 쓰면 대시 공격의 근접판이 나간다. 이동 사양서 4.4절 "근접 무기 → 근접 공격 시점 모드"가 이것이다.
  - 속력은 대시 공격 곡선 중 하나다(앞 2.5 / 45° 2.4 / 옆 2.25 / 135° 2.0 / 뒤 1.8 u/f).
  - 상대 거리 ≤ 15 u에서 정지한다.
  - 종료 후 경직은 0 / 8 / 16 f(변형별).
  - 세부 판정 창은 보지 않았다.

## 2. 피격 반응

### 2.1 반응 단계를 정하는 기준 — 높음 (구조), 중간 (종류 비트 해석)

반응은 **공격 종류**와 **누적 충격치** 두 축으로 정한다. 공격 종류만으로 결정되는 것도, 누적만으로 결정되는 것도 아니다.

**충격치 누적값**:
- 피격마다 그 공격의 충격치가 더해진다. 같은 프레임에 여러 발이면 합산한다.
- 매 프레임 1씩 줄어든다(템진). 일부 다른 기체는 2씩 준다.
- 다운·날아감·공중 다운으로 들어가면 0으로 지운다. **경직으로는 지우지 않는다.** 그래서 경직 중 추가 피격은 다운으로 이어지기 쉽다.

**판정값** = 충격치 누적값 + 행동 가산치.

**행동 가산치**:
- 공격 동작이 일정 단계에 이를 때마다 더해진다. 서기로 완전히 돌아가면 0이 된다.
- 템진: 사격 15~25(무기별), 근접 0, 기타 행동 10~50.
- 공격 동작 중에 맞으면 같은 공격에도 반응이 한 단계 무거워질 수 있다(중간).

**템진 문턱값**:

| 자세 | 경직 문턱 | 다운 문턱 | 날아감 문턱 |
|---|---|---|---|
| 지상 일반 | 200 | 600 | 1200 |
| 레버 모으기(앉은 자세) | 320 | 900 | 1300 |
| 점프 중(상승·하강) | 200 (반응 없음, 무적만) | 600 → 공중 다운 | — |

**판정 순서** (그 프레임에 피격 기록이 있을 때):

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | 근접 무적 중 + 근접 계열 피격 | 그 피격을 통째로 무시(피해·충격치 0). 무적 타이머는 그 프레임 줄지 않음 |
| 2 | 사격 무적 중 + 사격 계열 피격 | 같음 |
| 3 | 특수 구속계 종류 | 구속 상태 등 특수 경로(무기 범위라 생략) |
| 4 | 피해 적용, 충격치 누적 | |
| 5 | 강타 종류 | **날아감** |
| 6 | 점프 중 | 판정값 ≥ 600: **공중 다운** / 200~600: 반응 없음, 사격·근접 무적 16 f / < 200: 없음 |
| 7 | 판정값 < 경직 문턱 | 반응 없음(피해만). 근접 계열이면 피격측 히트스톱은 걸림(2.4절) |
| 8 | 경직 문턱 ≤ 판정값 < 다운 문턱 | 대시 중이면 반응 없음, 무적 16 f / 가드 중 근접이면 가드 경직 / 그 밖은 **경직** |
| 9 | 다운 문턱 ≤ 판정값 < 날아감 문턱 | 가드 중 근접이면 가드 경직 / 그 밖은 **다운** |
| 10 | 판정값 ≥ 날아감 문턱 | **날아감**(가드 무시) |

- 8번의 대시 예외: 지상 대시와 그 파생 상태에서는 경직급 피격에 반응하지 않고 대시를 이어 간다(슈퍼아머, 중간).
- 일부 사격 종류는 경직을 일으키지 않거나 이미 경직 중일 때 재경직을 일으키지 않는다(종류 식별은 무기 범위, 낮음).
- 다운 상태는 두 가지가 있다. 맞은 공격에 근접 계열 표시가 있으면 "근접 다운", 없으면 "사격 다운"이다. 미끄러지는 속력만 다르다.

**템진 근접이 템진을 맞혔을 때의 예**(행동 가산치 0, 누적 0에서 시작):
- A1 1타(충격치 500) → 경직.
- 경직 중 같은 공격 한 번 더 → 누적 1000 − 경과 프레임 → 다운.
- A1 2·3타(1100) → 다운.
- 강타 또는 C2(11000)·앉아 근접(20000) → 날아감.

### 2.2 반응별 동작

방향 규칙 — 높음:
- **밀려나는 방향 = 공격 방향.** 근접은 공격자에서 피격자 쪽으로 향하는 방위다. 사격은 탄의 진행 방위다.
- 모션 방향 분류는 공격 방향과 피격자 정면(상체 비틀기 포함)의 차로 정한다.

| 공격 방향 − 피격자 정면 | 의미 |
|---|---|
| −45° ~ +45° | 등 뒤에서 맞음 |
| +45° ~ +135° | 옆 1 |
| +135° ~ +225° | 정면에서 맞음 |
| +225° ~ +315° | 옆 2 |

- 경직은 4방향 모션 모두를 쓴다.
- 다운은 "등 뒤 → 앞으로 넘어짐", "그 밖 → 뒤로 넘어짐" 두 가지만 쓴다.
- 날아감은 4방향 모두를 쓴다.

#### 경직 — 높음 (흐름), 중간 (미끄럼 지속)

| 항목 | 값 |
|---|---|
| 지속 | 지상 2 f + 26 f = **28 f (0.47 s)**. 앉은 자세 4 f + 12 f = 16 f (0.27 s) |
| 밀려남 | 공격 방향으로 1.301 u/f (6.85 m/s), 히트스톱이 아닌 프레임마다. 근접 감속 × 0.78이 함께 걸림(중간) |
| 공중에서 | 점프 중이면 경직 대신 2.1절 6번 규칙. 공중 대시 등 점프 외 공중 상태에서는 지상 문턱으로 판정한다. 경직 상태에 중력 처리가 따로 없어서 공중 경직의 거동은 확인하지 못함(낮음) |
| 무적 | 경직 내내 사격 무적 유지. 근접으로 경직했으면 진입 시 근접 무적 16 f |
| 종료 | 서기. 사격으로 경직했으면 끝날 때 사격 무적 16 f를 더 준다 |

#### 다운 (사격 다운 / 근접 다운) — 높음

| 단계 | 지속 | 동작 |
|---|---|---|
| 띄움 | 착지 + 모션 24 f 이상 | 진입 시 vy = +1.4 u/f (7.4 m/s), 착지 플래그 해제. 중력 0.451 u/f² (142 m/s²), 낙하 상한 4.001 u/f. 수평 속력: 사격 다운 2.0 u/f (10.5 m/s), 근접 다운 1.6 u/f (8.4 m/s). 히트스톱 중에는 중력도 멈춤 |
| 누움 | 40 f | 진입 시 vy = +0.2(작은 튐). 수평 속력 = 기준 × (120 − 경과 f)/120로 선형 감속. 중력 절반, 착지 시 vy × −0.667로 튀다가 작아지면 멈춤 |
| 기상 대기 | 2.3절 | |

- 체공은 약 6 f(최고 약 2.2 u)라 금방 착지한다. 띄움 단계는 모션 길이 때문에 24 f 이상 이어진다.
- 미끄럼 거리 추정(× 0.78 미적용 기준): 사격 다운 48 + 67 = 115 u (10.1 m), 근접 다운 38 + 54 = 92 u (8.1 m). × 0.78을 적용하면 각각 7.9 m, 6.3 m(중간).

#### 날아감 — 높음

다운과 같은 구조다. 차이점만 적는다.
- 수평 속력 2.401 u/f (12.6 m/s).
- 띄움 모션 32 f.
- 누움 40 f.
- 미끄럼 추정 157 u (13.8 m), × 0.78 적용 시 10.8 m.

#### 공중 다운 (점프 중 다운 문턱 이상) — 중간

- 진입 시 vy = +1.901 u/f (10.0 m/s), 수평 2.0 u/f를 공격 방향으로 준다.
- 착지까지 떨어진다(최대 200 f).
- 착지 후 70 f 누움(수평 0) → 기상 대기.
- 공중 다운에는 다운 문턱만 쓴다. 날아감 문턱은 따로 보지 않는다(강타는 2.1절 5번에서 먼저 날아감).

### 2.3 기상과 다운 중 처리 — 높음 (흐름), 중간 (특수 입력)

**기상 대기**: 누움이 끝나면 기상 상태로 넘어간다. 대기 타이머 56 f(0.93 s)로 시작한다.
- 매 프레임 1씩 줄어든다.
- 레버·버튼을 연타 중인 프레임에는 1을 더 줄인다. 그래서 최소 28 f다.
- 대기 중 받는 입력(선입력):
  - 무기: 타이머 < 12일 때만.
  - 점프.
  - 대시 방향(대시 허가 필요).
  - 특수 입력(아래).

**대기 타이머가 0이 될 때 분기**:

| 선입력 | 결과 | 무적 |
|---|---|---|
| 근접 | 즉시 근접 공격 | 사격·근접 무적 16 f |
| 사격 | 즉시 사격 | 16 f |
| 특수 입력 | 이동 사양서의 "미확인 대시 파생 상태"로, vy = ±3.25 (기상 회피 동작으로 추정, 낮음) | — |
| 대시 방향 | 대시. 이동 방위 = **상대 방위** + 대시 오프셋(일반 대시와 달리 상대 기준) | — |
| 점프 | 점프 | — |
| 없음 | 기상 모션 30 f (0.5 s) | 아래 |

- 기상 모션이 끝나면 **사격·근접 무적 64 f (1.07 s)**를 받는다. 그 시점에 선입력이 있으면 바로 그 행동으로 넘어가고, 없으면 서기로 간다.
- 즉, 바로 행동으로 일어나면 무적이 16 f로 짧다. 그냥 일어나면 64 f로 길다.

**다운 중 무적**:
- 띄움·누움·기상 대기·기상 모션 내내 사격·근접 무적 타이머를 매 프레임 3 f로 다시 채운다. 기상 대기 중에는 3~6 f(난수)로 채운다.
- 이 무적은 "사격 계열 대부분 + 근접 계열"만 덮는다. 일부 특수 공격 종류는 통과한다(종류 식별 미완, 중간).

**다운 중 추가 피격**(무적을 통과한 종류가 기상 대기 중에 맞은 경우):
- 다운 추격 전용 종류: 튕김 모션 40 f를 재생한 뒤 대기로 돌아간다. 피해 상한은 50이다. 사격 무적 16 f를 받는다.
- 그 밖의 통과 종류: 튕김 모션을 재생하고 대기 타이머에 64 f를 더한다. 근접 무적 16 f를 받고, 충격치 누적을 0으로 지운다.
- 확신도: 낮음~중간.

### 2.4 히트스톱·무적 타이머 공통 — 중간

**히트스톱**:
- 근접 계열 피격(일반 근접, 근접 계열 2·3, 강타, 다운 추격)을 받으면 피격자에게 15 f(0.25 s)가 걸린다.
- 동시에 피격자에게 근접 무적 4 f를 준다.
- 공격자도 일반 근접·강타를 맞혔을 때 15 f가 걸린다. 단 피격자가 이미 근접 무적이면 걸리지 않는다. 근접 계열 2·3을 맞혔을 때는 공격자에게 걸리지 않는다.
- 히트스톱 동안 일어나는 일:
  - 모션 진행은 15 f 중 2번만 한 칸씩 나아간다(사실상 정지).
  - 수평 이동은 0이다.
  - 다운계의 중력도 멈춘다.
  - 무적 타이머는 계속 준다.

**무적 타이머**:
- 사격 무적과 근접 무적은 따로 돈다. 매 프레임 1씩 준다.
- 덮지 못하는 종류의 피격이 오면 무시하고, 그 프레임은 타이머를 줄이지 않는다.
- 표준 길이: 반응 후 16 f, 정상 기상 후 64 f.

### 2.5 반응 중 받는 입력 / 못 받는 입력 — 높음

| 상태 | 받는 입력 | 못 받는 입력 |
|---|---|---|
| 경직 | 없음(모션 끝까지) | 이동, 선회(수동 선회 처리 없음), 점프, 대시, 무기, 가드 |
| 가드 경직 | 없음. 끝나면 가드 유지로 복귀 | 이동, 점프, 대시 |
| 가드 유지 | 레버 모으기 유지/해제, 근접 입력(반격) | 이동, 수동 선회, 사격(무기 입력이 있으면 가드 해제 조건이 됨) |
| 다운 띄움·누움, 공중 다운 | 없음 | 전부 |

## 3. 기체끼리 충돌

### 3.1 결론 — 중간

다음 경로를 모두 확인했으나 **두 기체가 서로를 밀어내는 일반 밀어내기 처리는 찾지 못했다.**
- 공용 피격 처리
- 근접 판정
- 근접 구동
- 이동 적분 전 구간
- 벽 보정
- 프레임 공용 처리
- 카메라

벽 보정에 상대 위치를 읽는 부분이 있으나 특정 스테이지의 문 영역 판정이다. 기체 밀어내기가 아니다.

대신 **겹침을 막는 장치는 근접·대시 공격 쪽 속력 제한에만** 있다.

| 장치 | 적용 대상 | 내용 |
|---|---|---|
| 정지 거리 | 근접 파고들기(추적 중), 대시 근접·대시 공격(추적 중) | 상대 거리 ≤ 12.5 u(A·B) / 15 u(C·대시)면 속력 0, 추적 종료 |
| 넘어가기 방지 | 같은 대상 | 프레임 이동량 ≤ 현재 상대 거리 |
| 근접 감속 | 모든 상태(이동 사양서 1.4절) | 상대 거리 < 200 u면 속력 × 0.78. 밀어내기는 아님 |

### 3.2 겹쳤을 때 / 대시 중 부딪혔을 때 — 중간

- 걷기·지상 대시·공중 대시·점프 이동에는 상대와의 거리 제한이 없다. 두 기체 중심이 서로 지나갈 수 있다(원본 동작으로 판단, 실기 확인 필요).
- 대시 중 상대와 부딪혀도 정지·튕김 처리는 없다. 대시는 이동 방위를 유지하고 그대로 지나간다. 대시 공격만 추적 중일 때 15 u에서 멈춘다.
- 겹친 상태에서는 상대 거리가 안쪽 원 반지름 이하다. 그래서:
  - 근접 구역(밀착)이 켜진다.
  - 레버 누적값은 근접 구역 표(이동 사양서 2.1절)를 쓴다.
  - 근접은 나가자마자 파고들지 않는다(정지 거리 이하라 속력 0).
- 재현 권장: 원본 충실 재현이면 밀어내기를 넣지 않는다. 넣는다면 원본에 없다는 사실을 명시하고, 반지름은 근접 정지 거리(12.5 u)를 기준으로 삼는 것이 원본 감각과 가장 가깝다.

## 4. 처리 순서

### 4.1 대전 한 프레임 — 높음

이동 사양서 1.1절에 공격·피격 단계를 끼워 넣은 순서다. 굵은 줄이 이번에 추가·정정한 부분이다.

1. 카메라 갱신(지난 프레임 상태 사용).
2. 공용 처리.
3. **탄 명중 판정: 1P 탄 → 2P, 2P 탄 → 1P.** 결과는 피격자의 "피격 기록"에 쌓이기만 하고 반응은 아직 없다(중간).
4. 기타 공용 처리.
5. 1P 기체 갱신(4.2절). 이 안에서 1P가 받은 피격 기록을 정산한다.
6. 1P 기체 고유 처리, 조준각 계산(1P, 2P).
7. **1P 근접 판정: 1P 공격 형상 vs 2P 피격 구 → 2P 피격 기록에 기록.** 이동 사양서에서 "1P 무기 처리(추정)"로 적은 자리가 이것이다.
8. 2P 기체 갱신. 3번의 탄 명중과 7번의 1P 근접 명중을 **이번 프레임에** 정산한다.
9. 2P 기체 고유 처리.
10. **2P 근접 판정 → 1P 피격 기록.** 1P는 **다음 프레임** 5번에서 정산한다.
11. 무기·탄 갱신(이동·발사), 표시·사운드.

비대칭 정리:
- 2P는 1P의 근접에 0프레임 지연으로 반응한다.
- 1P는 2P의 근접에 1프레임 지연으로 반응한다.
- 탄 명중은 양쪽 모두 같은 프레임에 반응한다.

### 4.2 기체 한 대의 갱신 안에서 — 높음

**① 사전 갱신** (이동 사양서와 같음)
- 입력 → 상태 보조 처리.
- 다운계 상태의 중력·튐 처리가 여기서 일어난다. 히트스톱 중에는 건너뛴다.

**② 본 갱신**
1. 지연 표적 갱신 → 상대 관계 계산.
2. 공용 처리: **근접 구역(1.1절)과 상대 거리 100 u 표시를 이 프레임 위치로 계산.**
3. 자동 선회·카메라 방위 처리: **근접 추적 회전(1.3절)이 여기서 일어난다.** 근접 시작 프레임에는 아직 모드가 설정되지 않아 다음 프레임부터 돈다.
4. **피격 정산**(이동 사양서의 "피격·다운 공용 처리(미분석)" 자리), 이 순서:
   1. 근접 무적·사격 무적 필터.
   2. 피해 적용, 충격치 누적.
   3. 히트스톱·근접 무적 4 f 부여.
   4. 반응 단계 판정(2.1절). 반응 상태로 **즉시 상태 번호를 바꾼다.**
   5. 피격 기록을 비운다.
   6. 무적 타이머를 1 줄인다.
   7. 체력이 0이면 사망 상태로 바꾼다.
5. 수평 속력 0 초기화.
6. **상태 본 처리.**
   - 4번에서 반응 상태로 바뀌었으면 같은 프레임에 그 반응 상태의 본 처리가 돈다. 이때 근접 판정 플래그가 꺼지고, 무적 3 f 유지 등이 적용된다.
   - 근접 공격 중이면 근접 구동이 단계·기준 속력·판정 창 플래그·입력 잠금을 정한다.
7. 상체 비틀기, 모션 갱신.
8. 이동 적분, 이 순서:
   1. 근접 감속 × 0.78.
   2. 히트스톱이면 수평 이동 0.
   3. 근접 추적 카운터와 속력 보정(1.3절: 32 f 제한, ±22.5° 밖 × 0.5, 정지 거리, 넘어가기 방지).
   4. 상태별 속도 벡터. 경직 미끄럼(히트스톱 아닐 때만), 다운·날아감·가드 경직은 공격 방향으로 민다.
   5. 지면, 벽 보정, 위치 적분.
9. 히트스톱 카운터를 1 줄이고 모션 프레임을 진행한다. 히트스톱 중에는 8 f마다 한 칸만 진행한다.
10. 지연 요청 반영(단계·모션 프레임 변경).

**한 프레임 안의 인과 요약**:
- 근접 구역 판정 → (같은 프레임) 무기 입력이 근접으로 변환된다.
- 근접 판정 창 플래그 → (같은 프레임, 갱신 이후) 근접 명중 판정 → 상대의 다음 정산 때 반응.
- 반응 상태 진입 → (같은 프레임) 상태 본 처리가 판정 플래그를 끄고 무적을 건다 → (같은 프레임) 이동 적분이 밀려남을 반영한다.

## 6. 1차 미확인 해소

### 6.1 피격 구(몸통 판정) — 높음 (수치), 낮음 (부위 이름)

근접 명중 판정용 피격 구는 기체 종류별 고정 표에 있다. 반지름에는 기체 크기 배율(평상시 1.0)을 곱한다.

| 번호 | 붙는 관절 | 반지름 | 환산 |
|---|---|---|---|
| 0 | 관절 0 (기준 관절, 허리 추정) | 2.4 u | 0.21 m |
| 1 | 관절 7 | 2.5 u | 0.22 m |
| 2 | 관절 8 | 2.19 u | 0.19 m |
| 3 | 관절 5 | 2.2 u | 0.19 m |
| 4 | 관절 6 | 2.2 u | 0.19 m |
| 5 | 관절 1 | 2.19 u | 0.19 m |
| 6 | 관절 2 | 2.19 u | 0.19 m |

**자세에 따라 쓰는 구의 수가 줄어든다** (높음):

| 상태 | 쓰는 구 |
|---|---|
| 지상 전반 | 0~6번, 7개 |
| 점프 상승 단계 (및 세부 단계 3) | 0~2번, 3개 |
| 점프 하강 단계 | 0~1번, 2개 |

즉 점프 중에는 근접에 맞는 면적이 크게 줄어든다. 사격 명중은 이 표를 쓰지 않는다. 사격은 탄과 기체 중심점 사이 거리로 판정한다(중간).

### 6.2 공격 형상(칼 판정)과 길이 — 중간 (구조), 낮음 (실제 길이)

공격 형상은 네 종류다.

| 종류 | 판정 방식 |
|---|---|
| 궤적 면 | 두 관절(칼 밑동·칼끝)을 쓴다. "지난 프레임 밑동과 이번 프레임 밑동의 중점", "지난 프레임 칼끝", "이번 프레임 칼끝"으로 만든 면이 피격 구와 닿는지 본다. 공격측 반지름은 없다. 한 프레임 사이에 칼끝이 쓸고 지나간 부채꼴 면이 판정이다. 표시가 붙은 형상은 밑동을 관절 높이에 둔 기체 중심축 위의 점으로 대신한다 |
| 구 | 관절 하나 + 반지름. 중심 거리 < 두 반지름 합이면 명중 |
| 관절 방향 타원체 | 두 관절 사이 + 반지름. 관절 회전을 따른다 |
| 대형 구 | 반지름 40·65 u. 템진 근접에는 쓰지 않는다 |

**템진 근접 → 형상 대응**:

| 공격 | 형상 | 관절 | 반지름 |
|---|---|---|---|
| A1 1·2타, 앉아 A, 가드 반격 A, 다운 추격 | 궤적 면 1 | 관절 37 → 관절 35 | — |
| B1 1·2타, C1, A2, C2, 대시 근접 A·B·C, 점프 근접 A·B·C, 근접 스텝 근접, 앉아 C, 가드 반격 B | 궤적 면 0 (중심축 시작) | 기체 중심축(관절 37 높이) → 관절 23 | — |
| B2 | 관절 방향 타원체 + 구 | 관절 3 → 15 / 관절 15 | 2.0 u (0.18 m) / 4.0 u (0.35 m) |
| 앉아 B | 궤적 면 두 개 | 관절 12 → 10, 관절 11 → 9 | — |
| A1·B1 3타 | 없음(형상 0개) | — | — |

**"길이"에 대해**:
- 궤적 면은 관절 위치를 그대로 쓰므로 칼날 길이는 골격 데이터가 정한다.
- 템진 모델 골격 표의 국부 오프셋은 관절 35가 부모에서 19 u(1.67 m), 관절 37이 −9 u(−0.79 m), 관절 23이 50 u(4.39 m)다.
- 관절 37→35가 실체 칼(약 28 u 폭으로 추정), 중심축→관절 23이 빔 칼날을 늘린 긴 판정으로 보인다.
- 골격 계층을 복원하지 못해 실제 월드 길이는 확정하지 못했다(낮음).

**템진 근접 전 종류**(피해 / 충격치 / 피격 판정 종류):

| 공격 | 피해 | 충격치 | 종류 |

| A1 1타 (버튼 A, 서서) | 290 | 500 | 일반 근접 |
| A1 2타 | 130 | 1100 | 일반 근접 |
| B1 1타 (버튼 B) | 340 | 750 | 일반 근접 |
| B1 2타 | 180 | 1100 | 일반 근접 |
| C1 (버튼 C) | 380 | 1100 | 일반 근접 |
| A2 (터보 + A) | 435 | 1100 | **강타** |
| B2 (터보 + B) | 410 | 1100 | **강타** |
| C2 (터보 + C) | 460 | 11000 | **강타** |
| 앉아 A / B / C | 220 / 260 / 340 | 20000 | 일반 근접(앉아 표시) |
| 대시 근접 A / B / C | 275 / 275 / 325 | 1100 | 근접 계열 2 |
| 점프 근접 A / B / C | 340 / 370 / 340 | 1100 | 근접 계열 3 |

- 충격치 1100은 다운 문턱(600) 이상, 날아감 문턱(1200) 미만이다. 그래서 대부분의 근접은 한 방에 다운이다.
- 문턱 아래인 것은 A1 1타(500, 경직)와 B1 1타(750, 다운), 가드 반격뿐이다.
- 근접 스텝 중 근접의 방향 구분은 스텝 방향(앞·옆·뒤 계열)으로 정해진다.

**피해 보정** (공격자·피격자 상태별, 높음):

| 조건 | 피해 | 충격치 누적 |
|---|---|---|
| 피격자 가드 중 + 일반 근접(앉아 아님) 또는 근접 계열 2·3·강타 | × 6% | 강타 × 20%, 그 밖 근접 × 10% |
| 피격자가 터보 근접(A2·B2·C2) 중 + 앉아 근접에 맞음 | × 120% | 그대로 |
| 피격자 레버 모으기 자세 + 근접이 아닌 공격 | × 80% | 그대로 |
| 그 밖 | 기본(대전 설정 배율·남은 시간 보정 적용) | 그대로 |

가드 중 충격치가 10%만 쌓이므로, 가드가 충격치 누적으로 깨지려면(1200) 일반 근접 1100짜리를 11번 넘게 받아야 한다. 실전에서 가드를 깨는 것은 강타와 앉아 근접(20000 × 10% = 2000)이다.

### 6.4 근접 버튼과 실제 입력 — 높음 (비트 대응), 중간 (좌·우 명칭)

패드 입력은 레버마다 "방향 4비트 + 트리거 + 터보"로 묶인다.

| 문서상 이름 | 실제 입력 | 근접 구역 |
|---|---|---|
| 버튼 A | **오른쪽 레버 트리거** 단독 | 70 u, 반각 42° |
| 버튼 B | **왼쪽 레버 트리거** 단독 | 60 u, 반각 51° |
| 버튼 C | **두 트리거 동시** (약 3 f 이내) | 100 u, 반각 32° |
| 터보 A / 터보 B | 왼쪽 / 오른쪽 레버의 엄지 버튼 | — |

- 단독 트리거는 누른 뒤 약 2 f 동안 다른 트리거를 기다린 뒤 단독으로 확정한다.
- "좌·우"는 이동 사양서의 "레버 A = 왼쪽 레버"(중간) 가정에서 나온다. 가정이 반대면 A·B도 반대다.
- 원작 용어로는 버튼 A = 오른쪽 무기(RW), 버튼 B = 왼쪽 무기(LW), 버튼 C = 센터 무기(CW)에 해당한다.

## 7. 무기 유도

### 7.1 록온 — 높음

탄의 좌우 유도는 **발사 순간 록온 상태**일 때만 켜진다. 록온 판정은 매 프레임 조준각 계산 단계에서 한다.

| 조건 | 결과 |
|---|---|
| 상대가 어느 근접 구역 안 | 무조건 록온 |
| 록온 아님 + 상대 방위 오차 ≤ ±3.5° + 상하 각이 −20.4° 경계 안 | 록온 걸림 |
| 록온 중 + 상대 방위 오차 > ±29.5° 또는 상하 각이 −23.9° 경계 밖 | 록온 풀림 |
| 점프·공중 대시·급강하·공중 행동 중 | 상하 각 조건 생략(0으로 취급) |

- 걸리는 각(3.5°)과 푸는 각(29.5°)이 크게 다르다. 일단 걸리면 잘 풀리지 않는다.
- 록온이 걸려 있으면 조준점 = 상대 몸통 중심점이다. 풀려 있으면 정면 고정점이다.

### 7.2 발사 방향 — 중간

- **록온 상태**: 발사 방향은 상대 몸통 중심을 향한다. 무기별 상하·좌우 허용 각으로 자른다. 탄에 "3축 유도" 표시가 붙는다.
- **록온 아님**: 기체 정면·피치 + 무기별 고정 오프셋으로 쏜다. 3축 유도 표시가 없다.

### 7.3 프레임당 유도 — 높음 (구조), 낮음 (템진 무기별 대응)

매 프레임 탄에서 상대 몸통 중심을 본 방향(상하각·방위각)과 탄의 현재 방향 차를 구해, 축마다 정해진 한도만큼 돈다. 무기 정의에 유도 구간 세 개가 있다.

| 구간 | 조건 | 상하 회전 한도 | 좌우 회전 한도 |
|---|---|---|---|
| ① 초기 유도 | 탄 나이 ≤ 초기 유도 길이 | 초기 상하율 | 초기 좌우율 (3축 유도 탄만) |
| ② 후기 유도 | 무기에 후기 유도 표시 + 시작 나이 < 탄 나이 ≤ 끝 나이 | 후기 상하율 | 후기 좌우율 (3축 유도 탄만) |
| ③ 근거리 유도 | 무기에 근거리 표시 + (3축 유도 탄 또는 무기 강제 표시) + 탄–상대 거리 < 근거리 반경 | 근거리 상하율 | 근거리 좌우율 |
| 그 밖 | | 0 (직진) | 0 |

**3축 유도 표시가 없는 탄(록온 없이 쏜 탄)은 ①·② 구간에서 상하로만 유도되고 좌우로는 휘지 않는다.**

**유도가 시작되는 지연**:
- ①은 발사 첫 프레임부터 돈다. 지연이 없다.
- ②는 무기별 시작 나이부터 돈다. ①이 끝난 뒤 다시 꺾이는 "늦은 유도"다.

**끊기는 조건**:

| 원인 | 결과 |
|---|---|
| 탄 나이가 유도 구간을 벗어남 | 직진 |
| 발사 순간 록온 아님 | 좌우 유도 없음(상하만) |
| 상대가 회전 한도보다 빠르게 옆으로 빠짐 | 한도만큼만 돌아 빗나감 |
| 근거리 유도 반경 밖으로 벗어남 | 근거리 회전율 해제(①·② 구간 값으로 돌아가거나 직진) |

- **상대의 대시·점프 자체로 유도를 끊는 처리는 범용 탄 이동 경로에 없다**(중간). 표적점은 매 프레임 상대의 현재 몸통 중심이다.
- 대시가 유도를 피하는 것은 순전히 "상대의 옆 이동 속도 > 탄 회전 한도 × 거리"이기 때문이다.
- 점프는 상하 회전 한도를 넘는 고도 변화로 피한다.
- 일부 무기 종류는 전용 이동 처리를 따로 갖고 있어 예외가 있을 수 있다(낮음).

**템진 무기 정의 표의 값 범위** (144개 항목, 실제 무기·버튼과의 대응은 미확인):

| 항목 | 값 범위 | 환산 |
|---|---|---|
| 초기 상하율 | 0~613 단위/f | 0~3.37°/f |
| 초기 좌우율 | 0~512 단위/f, 흔한 값 72·144·160·200 | 0.40~1.10°/f, 최대 2.81°/f |
| 초기 유도 길이 | 12~300 f, 흔한 값 20~37 / 150 / 255 | |
| 후기 유도 회전율 | 16~88 단위/f (일부 256) | 0.09~0.48°/f |
| 후기 구간 | 16~54 f째부터 60~400 f째까지 | |
| 근거리 회전율 / 반경 | 32~112 단위/f / 20~150 u | 0.18~0.62°/f / 1.8~13.2 m |

## 8. 선입력 (다음 행동 입력을 미리 받아 주는 창)

공통 원리 — 높음:
- **무기 버튼**: 확정 프레임에만 사격으로 읽힌다. 근접 변환은 확정 후 1~4 f 동안 구역을 계속 확인한다. 이것이 사실상 근접 선입력 창 4 f다.
- **대시**: 서기·걷기에서 "터보를 누른 지 15 f 이내 + 그 터보를 계속 누르고 있음 + 레버 방향"이면 대시가 나간다. 그래서 다른 동작이 끝나기 최대 15 f 전에 터보를 눌러 두면 첫 서기 프레임에 대시가 나간다.
- **점프**: 레버 벌리기 새 입력 프레임에만 읽힌다. 기상 대기를 빼면 미리 받아 두는 창은 없다.

| 상황 | 받는 선입력 | 창 | 확신도 |
|---|---|---|---|
| 지상 대시 종료 단계 (16 f) | 무기(종료 3 f째부터 즉시 실행), 점프(언제든 즉시 실행). 다음 대시는 종료 후 서기에서 터보 15 f 창으로 | 무기 13 f, 점프 16 f, 대시 터보 15 f 전부터 | 중간 |

| 근접 ② 공격 단계 | 같은 버튼 재입력 → 다음 타 예약(템진 1타 중만) | ② 단계 전체 | 높음 |

| 근접 ③ 후딜 (앉아·강타) | 잠금 끝(24~46 f) 전에는 없음 | — | 중간 |

| 기상 대기 (56 f, 연타 시 최소 28 f) | 무기(타이머 < 12일 때), 점프(언제든 예약), 대시 방향(종료 순간 판정), 특수 입력 | 무기 마지막 12 f, 점프 대기 전체 | 높음 |

## 9. 히트스톱 경우별 — 높음 (조건), 중간 (가드 시 공격자)

히트스톱 길이는 **경우와 무관하게 15 f 한 가지**다. 걸리느냐 마느냐만 달라진다.

| 경우 | 맞은 쪽 | 때린 쪽 |
|---|---|---|
| 일반 근접으로 반응 없음 / 경직 / 다운 / 날아감 | 15 f + 근접 무적 4 f | 15 f (맞은 쪽이 이미 근접 무적이 아닐 때) |
| 강타로 날아감 | 15 f | 15 f |
| 가드됨(가드 경직) | 15 f (가드 경직 16 f는 그 뒤 진행) | 15 f (가드 첫 타라 근접 무적이 아닐 때) |
| 대시 근접(근접 계열 2) | 15 f | **멈추지 않음** |
| 점프 근접(근접 계열 3) | 15 f | **멈추지 않음** |
| 다운 추격 공격 | 15 f | 15 f |
| 사격 | 없음(사격 무적 4 f만) | 없음 |
| 무적으로 무시된 피격 | 없음 | 맞은 쪽 근접 무적 중이면 없음 |

**히트스톱 중 동작**:
- 모션은 남은 프레임이 8과 0일 때만 한 칸 진행한다(15 f 중 2칸).
- 수평 이동은 0이다.
- 다운계 중력도 멈춘다.
- 무적 타이머와 입력 카운터는 계속 돈다.

**경우별 체감 차이**:
- 날아감·다운 자체는 히트스톱이 끝난 뒤 띄움 단계가 시작된다.
- 길이가 같으므로 체감 차이는 반응 모션 차이뿐이다.

## 10. 카메라 모드 전환

### 10.1 하위 모드 선택 — 높음

매 프레임 자신과 상대의 상태로 고른다. 위에서부터 먼저 맞는 것을 쓴다.

| 순서 | 조건 | 모드 | 설정값(시선 피치 오프셋 / "거리" 값) |
|---|---|---|---|
| 0 | 특수 근접 상태의 연출 구간 | 특수 연출 카메라 | 별도 |
| 1 | 자신이 지상·대시 근접 공격 중 | **근접 공격 카메라** | ±4096 단위 범위 / 60·80 |
| 2 | 자신이 점프 근접 중(마지막 단계 12 f 전까지) | 점프 근접 카메라 | 9216 → 768 단위 / 84 |
| 3 | 자신이 다운 추격 공격 중 | 추격 카메라 | — / 58 |

- **근접 카메라 전환 조건은 근접 구역 플래그 그 자체다**(원뿔 또는 안쪽 원, 버튼 A·B·C 어느 것이든).
- 근접 구역 계산이 높이차 창을 포함하므로, 높이차가 2.1 m를 넘거나 1.1 m 아래로 벌어지면 원거리 카메라로 돌아간다.

### 10.2 값의 역할 — 중간 (높이), 낮음 ("거리")

- **시선 표적 높이**: 기준 높이 + 모드별 오프셋을 기체 회전으로 돌린 국부 오프셋이다. 원거리 모드는 +6 u(0.53 m)이고 매 프레임 차이의 12%로 수렴한다.
  - 공중 모드는 0~10 u 사이에서 시선 피치에 반비례해 낮아진다.
  - 확신도 중간.
- **시선 피치 오프셋**:
  - 원거리: 1536 단위(8.4°) 고정.
  - 공중 모드: 상대와의 높이차·거리로 계산한 각. 상한 12288 단위(67.5°).
  - 확신도 높음.
- **"거리" 값(58~84)**: 모드마다 정확히 설정된다. 하지만 이 값을 읽어 눈 위치를 정하는 처리를 게임 모듈 안에서 찾지 못했다. 거리인지 화각(도)인지 확정하지 못했다(낮음). 근접일수록 값이 작다(근접 공격 60 < 근접 66 < 원거리 78).

### 10.3 점프 중·다운 중 — 중간

- **점프 중**: 공중 카메라(10.1의 4·5번)가 높이차에 맞춰 시선을 들어 올린다(최대 67.5°). 이륙 직후에는 자동 선회 "점프 조준" 모드가 카메라 방위를 기체 방향 쪽으로 최대 22.5°/f로 추종시킨다.
- **다운 중**:
  - 사격 다운 띄움·누움 단계와 공중 다운에서는 시선 표적이 **자기 몸통 중심**으로 바뀐다.
  - 근접 다운·날아감에서는 자동 선회 모드가 강제로 "피격 시점"이 된다. 카메라 방위만 상대 쪽으로 최대 22.5°/f로 돈다.
  - 자신이 사격 다운이면 근접 구역 안이어도 원거리 카메라를 쓴다.

## 11. 이동 남은 조각 (요약 — 본문은 이동 사양서)

| 항목 | 결과 | 확신도 |
|---|---|---|
| 근접 스텝 방향별 속도 | 시작 → 끝: 앞 1.5→2.9, 앞 대각 4.2→2.4, 옆 4.2→2.2, 뒤 대각 2.5→1.95, 뒤 1.2→1.8 u/f | 높음 |
| 대시 중 방향 재입력 | 지속 단계 + 직전 프레임 두 레버 중립 + 새 방향 + 정반대 계열 아님. 터보 불필요. 이동 방위 = 현재 기체 방향 + 새 오프셋 | 높음 |
| 하강 가속 | 하강 중 레버 모으기 k번째 프레임(k ≤ 14)에 vy −= 0.2(k+1). 상한은 다음 프레임 적분 뒤에 걸려 실효 낙하 1.45 → 7.05 u/f, 15 f 누적 약 64 u(5.6 m) | 중간 |

## 12. 방위 부호 확정 — 높음

| 경로 | 쓰는 식 |
|---|---|
| 이동 적분(대시·근접·피격 밀림·상태별 속도) | vx −= 속력 × sin(방위), vz += 속력 × cos(방위) |
| 이동 적분(서기·걷기·점프의 레버 벡터) | vx −= 속력 × (전후 × sin + 좌우 × cos), vz += 속력 × (전후 × cos − 좌우 × sin) |
| 상대 방위 계산 | 방위 = atan2(내 x − 상대 x, 상대 z − 내 z) |
| 근접 구역 원뿔 꼭짓점 | 내 위치 − k × (−sin, cos) |
| 탄 발사·유도 | 같은 방위 함수 사용 |

- **정면 단위벡터 = (−sin 방위, cos 방위)**. 이동 사양서 0장의 "x = sin"은 틀렸고 정정했다.
- 레버 좌우 성분 +는 정면 + 90° 방향이다.
- +방위 회전은 정면을 +z에서 −x 쪽으로 돌린다. 이것을 화면상 왼쪽이라고 부를지는 렌더러 좌표계에 달려 있어 실기 확인이 남았다(중간).
