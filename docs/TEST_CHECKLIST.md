# 에디터 확인 체크리스트

Claude Code가 태스크마다 항목을 추가한다. 사용자는 플레이 모드에서 확인하고 체크한다.
형식: `- [ ] (태스크) 무엇을 하면 → 무엇이 보여야 한다`


## Phase A

- [ ] (A0) 컴파일 → Console에 에러 0개
- [ ] (A0) 플레이 → 마우스 왼쪽(또는 패드 RT)으로 공격, 마우스 오른쪽(또는 패드 LT)으로 가드가 이전처럼 동작
- [ ] (A0) 패드 LB → 앵커 클로, RB → 임팩트 슬램 발동 (키보드 Q/E도 그대로)
- [ ] (A0) 키보드 A/D 빠르게 두 번 → 사이드스텝 (이전과 동일)
- [ ] (A0) 패드 오른쪽 스틱으로 시점 회전 → 프레임레이트와 무관하게 일정한 속도 (마우스 감도는 이전과 동일)
- [ ] (A0) 더미에게 펀치·슬램·태클 → 더미만 맞고 내 HP는 줄지 않음
- [ ] (A0) 더미가 가까이 와서 공격 → 내 HP가 줄어듦 (더미가 나를 상대로 인식)
- [ ] (A0) 더미를 카메라 정면에 두면 락온 마커가 더미 위에 표시됨
- [ ] (A0) 플레이 중 Hierarchy에서 Mech·DummyTarget 선택 → `MechIdentity`가 붙어 있고 Opponent가 서로를 가리킴
- [ ] (A1) 더미에게 천천히 다가감 → **기체**와 더미 사이가 6m 이하가 되는 순간 카메라가 더미를 추적하기 시작하고 공격 버튼이 펀치가 됨 (Scene 뷰에서 거리 확인)
- [ ] (A1) 하드 락온 상태에서 뒤로 물러남 → 7m를 넘으면 추적 해제, 공격 버튼이 다시 사격(현재 단계)으로
- [ ] (A1) 하드 락온 중 시점을 크게 돌림(±60° 밖) → 추적 해제
- [ ] (A1) 더미와 나 사이에 엄폐물(Coverfull)을 둠 → 락온 마커가 사라짐
- [ ] (A1) 더미를 화면 밖으로 → 카메라가 더 이상 더미 쪽으로 끌려가지 않음
- [ ] (A2) 전력질주로 부스트를 0까지 씀 → 게이지가 빨간색(탈진), 달리기·질주·사이드스텝·퀵턴 불가
- [ ] (A2) 탈진 후 걷기/정지 → 부스트가 **50%** 에 도달하는 순간 색이 원래대로 돌아오고 달리기 가능 (이전엔 100%)
- [ ] (A2) 걷기/정지 중 가드(우클릭/LT)를 누르고 있음 → 부스트가 전혀 차지 않음. 가드를 놓으면 회복 지연(0.5초) 후 다시 참
- [ ] (A2) 가드를 오래 누르고 있음 → 부스트가 줄지 않음 (가드 비용 없음)
- [ ] (A2) 탈진 상태에서 가드 → 가드가 정상적으로 올라감
- [ ] (A3) 하드 락온 상태에서 펀치 1회 → 히트 게이지가 약 6% 오름 (빗나가도 오름)
- [ ] (A3) 펀치를 계속 연타해 히트 100% → 게이지 빨간색, 공격 버튼을 눌러도 펀치가 안 나감
- [ ] (A3) 과열 후 기다림 → 0%까지 식어야 색이 돌아오고 펀치 가능 (중간에 다시 눌러도 안 나감)
- [ ] (A3) 앵커 클로·임팩트 슬램 사용 → 히트가 오르지 않음
- [ ] (A4) 테스트 준비: 더미 공격을 받으려면 더미 근처에서 가드. 내 HP 감소량을 HUD로 확인 (더미 펀치 25)
- [ ] (A4) 가드를 미리 올려 둔 채(0.15초 이후) 더미 펀치를 받음 → HP 12.5 감소(50%), 히트 +10%
- [ ] (A4) 히트를 100%(과열)로 만든 뒤 가드로 받음 → 가드가 풀리고 HP 25 감소, 0.9초 동안 움직이지 못함(스턴)
- [ ] (A4) 가드를 놓자마자 다시 누름 → 0.4초 동안 가드가 안 올라감 (Inspector Debug 모드에서 MeleeSystem.IsGuarding 확인)
- [ ] (A4) 스턴 중 가드 버튼 → 가드 안 올라감
- [ ] (A4) 전력질주 차징 태클로 가드 중인 더미를 침 → 감쇄 없이 피해 (더미는 가드를 안 하므로 B1 2인 구성에서 재확인)
- [ ] (A5) 더미 펀치 직전에 가드를 새로 누름(0.15초 안) → HP 감소 0, 히트 증가 0
- [ ] (A5) 패리 성공 직후 가드를 놓고 바로 다시 누름 → 대기 없이 즉시 가드가 올라감 (평소엔 0.4초 대기)
- [ ] (A5) 태클 패리는 B1 2인 구성에서 확인: P2가 패리 → P1(태클한 쪽)이 태클 피해만큼 HP가 줄고 뒤로 밀려남, **P1은 스턴 없이 바로 움직일 수 있음**
- [ ] (A5) 태클이 패리되지 않고 맞음 → 이전처럼 태클한 쪽이 0.5초 경직
