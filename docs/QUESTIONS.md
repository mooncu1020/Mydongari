# 질문과 임시 결정

스펙이 애매할 때 Claude Code가 고른 기본값과 질문을 적는다. 사용자가 답을 달면 다음 작업에서 반영한다.

| 태스크 | 질문 | 고른 기본값 | 사용자 답 |
| --- | --- | --- | --- |
| B4 | 차징된 전력질주로 상대에 닿기만 해도 태클이 자동 발동하는 기존 동작을 유지할까? | 유지 (버튼 태클과 둘 다) | 유지. |
| A0 | 새 패드 바인딩(RT/LT/LB/RB)은 `Gamepad` 컨트롤 스킴 그룹에 넣었다. 기존 Slide/Quickturn/Run/Skill 키보드 바인딩은 스킴 그룹이 비어 있는데, B1에서 장치 페어링 시 이 바인딩들이 P2 패드 플레이어에게도 열려 있을 수 있다. 그룹을 `Keyboard&Mouse`로 지정해도 될까? (기존 바인딩 수정이라 보류) | 기존 바인딩 그대로 둠 | Keyboard&Mouse로 지정. 기존 바인딩 수정 허용. → A9 반영 |
| A0 | 공격 패드 바인딩에 기존 `buttonWest`(X/□)도 남아 있다. RT와 둘 다 공격으로 둘까? | 둘 다 유지 (기존 바인딩 삭제 금지 규칙) | 둘 다 유지. |
| A1 | 소프트 락온 "정면 30° 원뿔"이 반각 30°(전체 60°)인지 전체 30°(반각 15°)인지? 현재 코드는 반각 30°. | 현재 동작(반각 30°) 유지 | 반각 30° 맞음. |
| A2 | 스펙의 "탈진 = 이동 속도 저하"를 현재 코드는 "달리기·질주 봉쇄(걷기 속도로 제한)"로 구현하고 있다. 걷기 속도 자체도 더 느리게 할까? | 현재 동작 유지 (추가 감속 없음) | 달리기 이상 봉쇄만으로 충분, 유지. |
| A3 | `HeatGauge.IsSkillActive`(true면 냉각 정지)는 어디서도 true로 세팅되지 않아 현재 아무 효과가 없다. "스킬은 히트를 올리지 않는다" 규칙과 직접 충돌은 없지만, 스킬 사용 중 냉각을 멈추는 의도였다면 스킬 쪽에서 켜 줘야 한다. 그대로 둘까, 지울까? | 그대로 둠 (동작 영향 없음, 라운드 리셋 때 false로 초기화) | 삭제. → A9 반영 |
| A3 | 전력질주 중 냉각 감소(`sprintCoolingPenalty`)가 0.2(=냉각 80% 유지)다. 스펙은 "크게 떨어진다/급감". 값을 올릴까? | 코드 값 유지, 인스펙터에서 조정 | 0.7로 변경(냉각 속도 30%). → A9 반영 (`sprintCoolingReduction`) |
| A4 | 가드로 막은(Guarded) 공격의 넉백은 적용할까? 스펙은 "슬램 패리 시 넉백도 없음"만 명시. | 가드해도 넉백은 적용, 패리·맞딜만 넉백 없음 | 준다, 유지. |
| A4 | 파일드라이버는 "잡기라 가드·패리 무시"와 "가드 감쇄 적용 유지"가 같이 적혀 있다. | 패리는 무시, 가드 감쇄(50%)·가드 히트·과열 가드 깨짐은 적용 | 가드·패리 모두 무시(관통). → A9 반영 |
| A4 | 가드 재사용 대기(0.4초) 중 버튼을 누르고 버티면 대기가 끝나는 순간 가드가 자동으로 올라가는데, 이때 패리 창도 열어 줄까? | 안 연다. 패리 창은 버튼을 새로 누른 순간 올라간 가드에만 | 기본값 유지. |
| A4 | "패리 성공 직후 대기 없음"의 유효 시간. | 패리 성공 후 다음에 가드를 내릴 때까지 유효 (시간 제한 없음) | 기본값 유지. |
| A4 | 가드 깨짐 스턴 동안 스턴 해제 후 바로 가드를 올릴 수 있게 할까? | 스턴 자체가 벌이라 깨짐·스턴으로 가드가 풀릴 땐 재사용 대기 없음 | 기본값 유지. |
| A8 | 라운드 시작 시 "앵커 클로·스킬 쿨타임 초기화"를 "즉시 사용 가능"으로 볼지 "방금 쓴 상태(쿨타임 처음부터)"로 볼지. 기존 코드는 게임 시작 직후 5초/8초 동안 못 쓰는 상태였다. | 즉시 사용 가능 (1라운드도 동일하게 적용) | 즉시 사용 가능, 유지. |
| A8 | 라운드 시작 시 펀치·태클 쿨다운도 즉시 사용 가능으로 초기화했다. | 즉시 사용 가능 | 즉시 사용 가능, 유지. |
